# SmartCar_FOC_Test_Code

STM32G474 dual-drive FOC project.

- main: modified engineering and test version (HRTIM, encoder, alignment and current-loop work).
- FOC_test1: preserved original AxDr project from the local copy.

Both branches use AxDr_L-main/AxDr_L-main/1.AxDr_Drag_VF as the firmware directory.
Open the repository root in VS Code. Check the selected branch before committing and pushing.
Build output and local editor settings are excluded.
